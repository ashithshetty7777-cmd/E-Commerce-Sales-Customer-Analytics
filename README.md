# E-Commerce Sales & Customer Analytics

## 📌 Project Overview

This project analyzes e-commerce sales and customer data using **MySQL**.

The goal was to answer practical business questions related to sales performance, customer spending, product performance, revenue trends, and customer behavior using SQL.

## 🗄️ Database

**Database:** `ecommerce_analytics`

### Tables

* `customers` — Customer information
* `products` — Product and pricing information
* `orders` — Order transactions

### Dataset Size

* 20 Customers
* 15 Products
* 50 Orders

## 🛠️ Tools & Technologies

* MySQL
* MySQL Workbench
* SQL
